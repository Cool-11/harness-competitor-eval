## 零点、五款统一规则：跨会话记忆一律关闭（对 `docs/01 §1` 的细化，待作者确认）

`§1` 规定"产品自带记忆/个性化保持默认；若其内容可能影响任务执行，可关闭并记录"。落地时需要**五款一致**的口径，否则它本身就成了变量：

| 功能 | 统一处置 | 理由 |
|---|---|---|
| **跨会话/长期记忆** | **统一关闭 + 截图留痕** | `§6.0` 要求每题新开会话；长期记忆会把历史偏好注入新会话，直接破坏会话独立性 |
| 产品自带个性化（语气/称呼等） | 保持默认，记录内容 | 不影响任务执行的不必动 |
| 个人加装技能/插件/自定义指令 | 统一停用 + 留痕 + 评测后恢复 | `§1` 明确要求 |
| 底层模型与默认参数 | 保持产品默认；**若被第三方工具改过则必须恢复默认** | 见 Codex 一节 |

> **Codex(DeepSeek) vs DSH(DeepSeek) 的差异 = 纯粹的 Harness 差异**

这条比原来的"DSH 换件"更有力：它把主实验里唯一一个"模型不同"的干扰项直接消掉，属于 `§4.2` 的 **A 级实测对照**。反过来也能做（若 ccswitch 的 model catalog 里有 MiniMax，把 Codex 切到 MiniMax-M3 与 DSH 同模型）。

**但注意两条纪律**：
- 这个对照**不能混进主表**——主表仍是"五款各自默认形态"（`§4.3` 要求换件结论单独成节）
- 主实验跑测期间**不要动** ccswitch 档位；同模型对照安排到 W9（`docs/01 §8` 排期里的"DSH 换件对照"窗口）
