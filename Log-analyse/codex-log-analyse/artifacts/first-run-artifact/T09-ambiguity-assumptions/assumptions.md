# 假设声明（T09）

## 一、题干歧义识别

1. **"第三季度"的口径歧义**：材料同时给出自然季口径（1—3 月为一季度）与财年季口径（财年自 4 月 1 日起算），二者的"第三季度"指向的月份完全不同。
2. **口径提示**：材料注明"历史对外披露材料中，两份口径均被使用过，未统一"，因此不能靠"公司惯例"唯一确定。
3. **数据一致性**：两套口径的四个季度金额完全相同（1,240 / 1,580 / 1,730 / 1,410，单位万元），只是季度划分的起点不同；数字本身无需取舍。

## 二、我采用的全部假设

1. **假设前提**：题干未出现"财年"字样，因此按日常语境把"2026 年第三季度"理解为自然年第三季度（7—9 月）。
2. **假设口径**：采用自然季口径表，取"三季度（7—9 月）"一行，金额 1,730 万元。
3. **假设单位**：表中金额单位为万元，答案同单位给出（1,730 万元），未做单位换算。
4. **假设货币**：材料未标注币种，按上下文作人民币理解，仅影响表述、不影响数值。
5. **假设范围**："营业收入"即材料所给的季度营业收入，不含其他口径（如含税/不含税、分部合并调整等）；材料未提供此类区分。
6. **假设数据完整**：假设 `quarterly.md` 两表数字即该公司 2026 年全部季度收入的准确值，未与其他材料交叉核对。
7. **假设四季度 1,410 万元属于 2026 年**：自然季表中标注为"四季度（10—12 月）"，按 2026 年内理解。

## 四、结论的影响范围

- 若提问者认可自然季口径：答案 1,730 万元（本文件正文采用）。
- 若提问方使用公司财年季口径：答案 1,410 万元。
- 无论采用哪种口径，都应**先声明口径再给数字**，否则同一份材料会得出不同答案——这正是本题的分歧点。
