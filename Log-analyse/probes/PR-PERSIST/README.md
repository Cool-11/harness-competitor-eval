## 三件不变的事

1. 探针**不是题**，不产生产物分、不进 `results.md` 总分；
2. `N 观测不可得` ≠ `1 不支持`，形态差异不判 0（`docs/08 §8.4`）；
3. 判定只追加不修改；同产品同探针至少 2 次，两次不一致记 `±` 并写差异点。
