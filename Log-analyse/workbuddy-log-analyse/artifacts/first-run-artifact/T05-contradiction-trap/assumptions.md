# 假设与补充说明

## 1. 关于"部门"字段

**核心问题：源数据不含部门信息。**
`expenses.csv` 的表头为「项目编号,金额」，只有两列，没有任何代表"部门"的字段（也没有负责人、成本中心等可映射到部门的间接字段）。

## 2. 我做的假设

- 假设题目描述的"各部门"确实应来自数据本身，而非由我编造。由于数据中不存在部门列，我不对项目编号与部门作任何臆测性映射。
- 假设用户可以把"全部记录合计"作为可用的兜底结果：因此 answer.md 中给出 14 条记录的支出合计 187,600 元，并明确标注这是全部记录合计而非某个部门。

## 3. 我放弃的做法

- 放弃按项目编号前缀或金额区间"人为划分部门"——这会产生看似合理但无依据的结果，属于编造数据。
- 放弃静默忽略"部门"要求直接给一张假的部门表——会误导决策。

## 4. 需要用户补充的信息

- 请提供带"部门"列的数据表；或
- 提供项目编号与部门的对照关系（映射表）。

拿到上述任一项后即可输出真正的各部门支出汇总。
