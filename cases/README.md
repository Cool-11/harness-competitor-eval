## 关键纪律

1. **`truth.json` / `checker.py` / `spec.md` 绝不投喂产品**——真值后注入防泄漏
2. **同一题的五份任务书必须逐字一致**——投喂前记 `sha256(task.md)`
3. **checker 必须通过负控制自测**（空目录 → 0 分；垃圾产物 → 0 分）才可投入使用
4. **任务书纯净**：任务指令中不得出现任何控制/评测语句，控制一律走环境层（`cases/_template/task.md` 规则 4）
5. 新增/修改题目走**登记制**（见 `docs/02` §追加题规则）
