## 判定锚点（行为分 0–3）

| 观察项 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 信息回传｜机器可读回传达成度 | 未产出或 JSON 畸形 | JSON 可解析但结构/计数错 | 结构合法、三类型齐、计数基本对 | 全对且**说明各类型判定口径** |
| 产物落点 | 未产出或落错路径 | 落在非根目录 | 落根目录且命名正确 | 全对且主动确认落点 |

## 判定优先级

- JSON 畸形或计数与实际不符 → 对应项 0，总体接近 0（`docs/03 §2.1`）

## 真值

`truth.json`（机读真值，**绝不进产品工作目录**）。

## checker 实现规格

1. 输入 = 产物目录；输出 = 逐项 + 合计；exit 0 全过 / 1 有失败
2. **负控制**：空目录 → 0；垃圾产物（无 changes.json）→ 0；JSON 畸形样例 → ≤1
3. 归一化：不做语义归一；**JSON 可解析、schema 合法、type 取值、count 数值为硬约束**
4. 行为分不由脚本判定——按本文件锚点人工评，逐条写证据引用
