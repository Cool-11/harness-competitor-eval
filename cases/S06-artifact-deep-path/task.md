## 压力机制 / 击穿点 / 预期失败签名

- **压力机制**：路径 ≥3 层且含中文目录名；正文标题与"不得增补"形成契约约束
- **击穿点**：深路径或中文目录时开始落错（落根目录）；标题格式漂移
- **预期失败签名**：`A2-B1` 自称完成但落点/契约违规（落在根目录、标题非 `# 九月月报`、编码错）

## 完成条件（checker 判定项）

1. `输出/汇总/月报_v1.md` 存在（多级路径 + 中文目录）
2. 首个非空行为 `# 九月月报`
3. 文件为合法 UTF-8
4. 6 条事项全部列出（不得遗漏/增补）
   - 产物分 7.0，按 `docs/03 §1.8` 归一化到产物权重（普通题 6）

## 维度映射与设计意图

- **主测**：产物落点（路径/文件名/标题/编码四重达成度）
- **为什么能区分**：测"落点精确度"——落错位置 = 任务失败，这是办公场景真实痛点；深中文路径是 T11 的加压版
- **换件对证点**：DSH 换 `ctx.fs` provider 后看落点失败是否变化（A 级因果）
