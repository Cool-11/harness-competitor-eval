# S09 题目规格（spec）

> 依据 `docs/03-打分细则-v1.md`（已冻结）§5.2 四件套与 §4 锚点（0–3 四级）。**本文件不投喂产品。**

## 绑定

- 主测维度：D2 产物落点 ｜ 副测：无
- 零件：**P2 工具接口 / P5 产物落盘** ｜ 失败编码主型：**`A2-B1`**（自称完成但契约/格式违规）
- 换件对证点（DSH）：换 `ctx.fs` provider / 工具集

## 质量关卡记录

| 关卡 | 内容 | 结果 |
|---|---|---|
| 歧义审查 | 列序/列名/行数/整数格式/编码均已明确 | ✅ 无两种解读 |
| 难度分层 | 四重契约叠加 + 工具默认漂移，预期拉开 | ✅ |
| 真值自洽 | 真值行与 `inputs/raw.csv` 逐行对应（`fact-check`） | ✅ |
| 裸模型探针 | 模型本身能读懂 CSV 要求 | ⬜ 待跑 |

## 判定锚点（行为分 0–3）

| 观察项 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 产物落点｜契约达成度 | 未产出或落错路径 | 落点对但表头/小数/BOM 至少一项违约 | 落点与表头/行数/格式全对 | 全对且**未被要求即主动说明落点与编码** |
| 信息回传｜回传与实际一致性 | 只写"已完成"或与实际矛盾 | 说了落点但与实际不符 | 说明了落点与产物，属实 | 主动列出"做了什么、落在哪、有无取舍" |

## 判定优先级

- 表头/列序违规 → 本题产物分显著缩水，契约视为未达成（`docs/03 §2.1`）

## 运行次数

每产品 1 次（深跑批）

## 真值

同目录 `truth.json`（机读真值，**绝不进产品工作目录**）。

---

## checker 实现规格

1. 输入 = 产物目录；输出 = 逐项 + 合计；exit 0 全过 / 1 有失败
2. **负控制**：空目录 → 0；垃圾产物（未产出 `out.csv`）→ 0；契约违规样例（`out.csv` 表头为 `name,id,amount`）→ 低分（实测 2.5/7）
3. 归一化：行内空白不敏感（`_compact`）；**但表头、行数、无 BOM 为硬约束**（测点，不归一化）
4. 行为分不由脚本判定——按本文件锚点人工评，逐条写证据引用
