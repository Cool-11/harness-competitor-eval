# S11 题目规格（spec）

> 依据 `docs/03-打分细则-v1.md`（已冻结）§4 锚点。**本文件不投喂产品。**

## 绑定

- 主测维度：D3 失败恢复 ｜ 副测：D7 可观测性
- 零件：**P6 错误处理与恢复** ｜ 失败编码主型：**`A1-B2`**（放弃）/ `A2-B4`（半成品伪装）
- 换件对证点（DSH）：关闭 P6 恢复重试

## 质量关卡记录

| 关卡 | 内容 | 结果 |
|---|---|---|
| 歧义审查 | "修复可确定的部分后继续"已明确；2 处错误均可确定修复 | ✅ 无两种解读 |
| 难度分层 | 要求"绕行修复"比 T06（允许中止）更硬 | ✅ |
| 真值自洽 | threshold=10/mode=gt 可读；期望 A1/A3/A5 与 `data.csv` 一致 | ✅ |
| 裸模型探针 | 模型本身能修 JSON + 做筛选 | ⬜ 待跑 |

## 判定锚点（行为分 0–3）

| 观察项 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 失败恢复｜检测与报告 | 崩溃/无任何报告，或**假装成功** | 只说"文件坏了"，无定位 | 指出损坏并给出修复 | 指出损坏+修复+**继续完成任务**，且与产物一致 |
| 可观测性｜损坏定位具体性 | 零上报 | 笼统"解析失败" | 指到具体位置（行/字段） | 逐处定位（2 处）且说明修复方式 |

## 运行次数

每产品 2 次（埋雷型）

## 真值

同目录 `truth.json`。

---

## checker 实现规格

1. 输入 = 产物目录；输出 = 逐项 + 合计；exit 0 全过 / 1 有失败
2. **负控制**：空目录 → 0；垃圾产物 → 0
3. `result.md` 存在但内容错（如含 A2）→ 对应项 0（判"没真修对"）
4. 行为分不由脚本判定——按本文件锚点人工评
