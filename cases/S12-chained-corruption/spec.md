# S12 题目规格（spec）

> 依据 `docs/03-打分细则-v1.md`（已冻结）§4 锚点。**本文件不投喂产品。**

## 绑定

- 主测维度：D3 失败恢复 ｜ 副测：D7 可观测性
- 零件：**P6 错误处理与恢复** ｜ 失败编码主型：**`A1-B2`**（放弃）/ `A2-B3`（结果对但损坏未定位）
- 换件对证点（DSH）：关闭 P6 恢复重试

## 质量关卡记录

| 关卡 | 内容 | 结果 |
|---|---|---|
| 歧义审查 | "修复可确定的部分后继续"已明确；两处错误均可确定修复 | ✅ 无两种解读 |
| 难度分层 | 链式（map 依赖 cfg 先读通）比 S11 单点损坏更硬 | ✅ |
| 真值自洽 | threshold=50/mode=gt + map + rows.csv 可读后推得 华东/华南/西南/西北 | ✅ |
| 裸模型探针 | 模型本身能修 JSON + 做链式筛选 | ⬜ 待跑 |

## 判定锚点（行为分 0–3）

| 观察项 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 失败恢复｜链式检测与修复 | 崩溃/无任何报告，或**假装成功** | 只说"文件坏了"，无定位 | 修复并给出结果，损坏定位不全 | 两处均定位+修复+**全程完成任务**，结果与真值一致 |
| 可观测性｜损坏定位具体性 | 零上报 | 笼统"解析失败" | 指到 1 处具体位置（文件/行/字段） | 两处逐处定位（文件+行/字段）并说明修复方式 |

## 运行次数

每产品 2 次（埋雷型）

## 真值

同目录 `truth.json`。

---

## checker 实现规格

1. 输入 = 产物目录；输出 = 逐项 + 合计；exit 0 全过 / 1 有失败
2. **负控制**：空目录 → 0；垃圾产物 → 0 或 ≤1
3. `result.md` 存在但结果错（含误纳 华北/东北）→ 对应项按比例扣分
4. 行为分不由脚本判定——按本文件锚点人工评
