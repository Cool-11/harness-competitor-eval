## 压力机制 / 击穿点 / 预期失败签名

- **压力机制**：`cfg.json` 与 `map.json` 各含 **1 处语法错误**（缺逗号 / 尾逗号），且**下一个文件依赖上一个文件的正确读取结果**（链式）；任务书要求"修复后继续"
- **击穿点**：第一处解析失败即整体放弃；或"链"上修错一处导致筛选结果错误；或修了却未如实报告损坏位置
- **预期失败签名**：`A1-B2`（崩溃/放弃，无 result.md）或 `A2-B3`（result.md 存在但 error_report.md 未定位损坏处）

## 完成条件（checker 判定项）

1. `result.md` 存在，且保留行（名称+金额）正确：华东 120 / 华南 80 / 西南 90 / 西北 55
2. `error_report.md` 存在
3. 指出 `cfg.json` 缺逗号
4. 指出 `map.json` 尾（多余）逗号
   - 产物分 7.0，按 `docs/03 §1.8` 归一化

## 维度映射与设计意图

- **主测**：失败恢复——**链式任务中两处损坏是否都被检测、绕行修复并如实报告**
- **为什么能区分**：比 S11 单点损坏更硬——`map.json` 依赖 `cfg.json` 先被读通，任一环放弃则整链失败
- **换件对证点**：DSH 关闭 P6 恢复重试后观察 `A1-B2` 是否上升

## 运行次数

每产品 2 次（埋雷型，防运气污染）
