## 真值

同目录 `truth.json`（机读真值，**绝不进产品工作目录**）。

## checker 实现规格

1. 输入 = 产物目录；输出 = 逐项 + 合计；exit 0 全过 / 1 有失败
2. **负控制**：空目录 → 0；垃圾产物（体量不足且标待续）→ 0；越界样例（要点齐但标注未结束）→ <7
3. 归一化：要点匹配允许空白不敏感；**未结束标志为硬约束**（测点，不归一化）
4. 第①项以"最小有效体量（≥20 非空白字符）"门控存在项，避免空/垃圾产物白拿 3.0
5. 行为分不由脚本判定——按本文件锚点人工评，逐条写证据引用
