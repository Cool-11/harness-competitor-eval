# 21 · 会话持久化维度对照表 v0.1（把 checkpoint 语义翻成黑盒探针）

> 触发：2026-10-29 复核 LangGraph checkpointer 文档后确认——"**状态能不能存住、能不能回到过去、断了能不能接着跑**"是五款 Harness 的真实差异面，但现有 `docs/09 §1.1` 的 D1–D7 全部只描述"**单次运行内**"的行为，没有一格能描述"跨进程 / 跨会话 / 可回溯 / 可分支"。

## 1. 为什么不能照抄 LangGraph 的一致性测试

LangGraph 敢做 conformance suite，是因为它有可断言的接口。桌面 GUI 没有这一层，硬套只会产出一堆"我觉得它有"。

| LangGraph 契约 | 可断言的东西 | 桌面 GUI 的现实 | 我们的替代判据 |
|---|---|---|---|
| `get_tuple(config)` 按 id 精确查 | 返回值是否为 `None` | 没有 API；只能"打开那个会话看看" | 动作可照做 + 结果可复现 |
| `put_writes` 落 task 级写 | 表里有几行 | 只能看"重跑时是否重复劳动" | **副作用可见性**（文件被重写几次） |
| `StateSnapshot.tasks[].interrupts` | 断言非空 | 只能看界面是否停在确认点 | 中断点前后的行为差 |
| `durability="sync"` | 落盘时机 | 只能"杀进程试一次" | 崩溃前后的丢失量 |
| conformance suite | `report.passed_all_base()` | 无对应物 | **同探针同产品两次是否给出同一答案**（自一致性，见 §6.2） |

**一句话**：把"接口一致性测试"降级为"**行为一致性探针**"——判据从 `assert` 变成「可复现观察 + 证据等级」。

## 3. 十条探针卡（每格照做即可，不需临场判断）

> 统一载体任务见 §4，**不用新题、不泄题、30 秒可跑完**，中断点天然可控。

| # | 动作（照做） | 观察点（只看这个） | 3 原生 | 2 可绕过 | 1 不支持 | N 观测不可得 |
|---|---|---|---|---|---|---|
| **P-01** | 载体任务跑完 → 新建第二个会话 → 托盘退出 → 重开 → 在历史里找第一个 | 列表是否在 / 标题能否辨识 / 有无搜索或重命名 / 跨重启是否稳定 | 列表+搜索+重命名+跨重启稳定 | 有列表，但标题无意义（一排"新对话"）或只能滚动找 | 只有"继续上次"，无列表 | 界面无任何历史入口 |
| **P-02** | 跑到第 2 步 → 彻底退出（非最小化）→ 10 分钟后重开 → 打开该会话 | 文本全文 / 附件是否仍挂 / **产物文件卡片是否仍可点开** | 全部原样，附件与卡片可用 | 文本在，附件或卡片失效需重挂 | 只保留最后若干轮或仅摘要 | 会话不落盘，关即失 |
| **P-03** | 单轮内做 3 个子步骤（读 → 写 → 校验），过程中看过程区，结束后回看这一轮 | 是否留逐步记录（工具调用/写入路径/校验结果），是否带时间 | 逐步可查且带路径与时间 | 只有"正在执行…"类摘要，结束后折叠不可展开 | 只留最终结论 | 过程区不存在（如不导出终端日志的桌面端） |
| **P-04** | 同一会话连跑 5 轮 → 滚到第 1 轮 → 再灌长材料触发压缩 → 重看第 1 轮 | 第 1 轮原文是否完整 / 压缩后是否被摘要替换 / 原文能否展开 | 原始消息永久保留且可展开 | 早期轮次被折叠但可展开 | 被摘要替换且不可找回 | 无向上滚动历史 |
| **P-05** | 回到第 2 轮 → 编辑其中要求 → 触发重新生成 | 新结果替换还是新增 / **旧分支能否找回** / 后续轮次是否被截断 | 生成新分支且旧分支可回切（等价"只追加"） | 替换但保留"上一版"可切换 | 直接覆盖，旧内容不可恢复 | 不支持编辑历史消息 |
| **P-06** | 第 2 步（写 `b.md`）执行中强制中断 → 重开 → 让它继续 | `a.md` 是否已在盘 / 续跑是否**重复写** `a.md` / 是否静默从头开始 | 已完成步骤保留且不重做，从断点续 | 产物保留，但从头重跑（重复动作可见） | 中断即整轮作废，需重下指令 | 无法中断后继续 |
| **P-07** | 执行中直接结束进程（任务管理器 / `taskkill`）→ 重开 | 丢几轮 / 未落盘产物丢多少 / 有无"上次异常退出"提示 | 恢复到中断前一步且有提示 | 恢复到上一轮完成点 | 丢多轮或整会话 | 崩溃后会话打不开 |
| **P-08** | 首轮给 3 条硬约束（禁用词 / 字数上限 / 固定标题）→ 灌长材料直到触发压缩 → 末轮要求产出 | 压缩是否可见 / 早期 3 条约束在末轮是否仍生效 | 压缩可见且约束不丢 | 压缩不可见但约束保住 | 压缩后约束失守 | 无压缩机制（长会话直接报错或硬截断） |
| **P-09** | 一个天然产生子任务的任务（批量处理 5 个文件 / 多步研究），要求逐个汇报 | 子任务是否有独立可见状态 / 主会话能否引用其结果 / 能否单独重试 | 子任务状态独立可查且可单retry | 有进度展示但不可单独回看 | 全部揉进一段文本 | 无子任务概念 |
| **P-10** | 导出会话 → 再删一个会话 → 查目录与设置里是否残留 | 导出格式（md/json/html）/ 是否含工具轨迹 / 删除是否真删 / 能否撤销 | 结构化导出含轨迹 + 真删 + 可撤销 | 仅文本导出，或删除仅隐藏 | 不可导出，或删除留残留 | 无导出无删除 |

## 4. 统一载体任务 `PR-PERSIST-v1`

**为什么必须统一载体**：探针要跨五款可比，动作就得逐字一致；而正式题（S/T 批）的耗时与中断点不可控，做不了"第 2 步掐断"。故另立一个**只服务探针**的最小任务，不进题库、不算分。

```text
在当前工作目录下依次完成三步，每步完成后再做下一步：
1. 创建 a.md，写入一行：STEP-A-OK
2. 读取 a.md，把内容原样写进 b.md，并在 b.md 追加一行：STEP-B-OK
3. 校验 b.md 是否包含两行，把校验结果写入 c.md，一行：PASS 或 FAIL
三步都完成后，只回复「已完成」三个字，不要总结。
```

设计要点：

- **三步强依赖**（b 依赖 a，c 依赖 b）→ 中断在第 2 步时，"a 是否保留""b 是否重算"一眼可辨（P-06 直接可判）
- **每步产物是常量字符串** → 不用 checker 也能肉眼判，且不引入内容质量噪声
- **末句"不要总结"** → 顺带压测 D5，且避免长输出污染观察
- 全程 < 30 秒，**单次探针成本可控**

载体原文已落盘：`Log-analyse/probes/PR-PERSIST/carrier_prompt.txt`，sha256 = `d2ad8a2b…1c50eb`（全值见该目录 `README.md`）。**改一个字即视为换版本**，须另起 run 目录。

现场落点（沿用 `Log-analyse/probes/` 既有先例 `U-05-deepseek/`）：

```
Log-analyse/probes/PR-PERSIST/<产品>/<P-编号>-run<n>/
  carrier_prompt.txt   # 载体任务原文（含 sha256）
  obs.md               # 逐条观察：时间戳 / 看到了什么 / 截图文件名
  shots/               # 每个观察点至少 1 张同源截图
  verdict.md           # 四态判定 + 证据等级 + 判定人 + 判定时间
```

## 6. 填表与证据规则

### 6.1 五态定义（拒绝二值化）

| 值 | 含义 | 记法 |
|---|---|---|
| `3 原生` | 产品形态内直接提供，无需绕 | 需 A 级证据 |
| `2 可绕过` | 原生没有，但有稳定替代路径（如手动导出再粘回） | 需写清"绕法"，否则降为 `未验` |
| `1 不支持` | 界面明确没有，且无替代 | 需 A/B 级证据 |
| `N 观测不可得` | 产品形态决定拿不到（无过程区、不导出日志） | **不判 0**，同 `docs/08 §8.4` 口径 |
| `未验` | 没做或证据不齐 | 默认值 |

### 6.2 一致性测试的最小实现（本维度特有要求）

LangGraph 的一致性靠测试套件，我们只能靠**重复**：

1. **同产品同探针至少 2 次**（建议不同日）；两次结论不同 → 格子里记 `3±` 这类带符号值，并在 `verdict.md` 写明差异点
2. **先看自一致性，再看跨产品**：连自己两次都对不上的格子，不参与横向比较
3. **同一观察者**：十条探针由一个评测者打，避免"什么叫'可展开'"理解不同；换人须先对 1 款做校准
4. **判定不可回改**：`verdict.md` 只追加，不修改历史判定（同 `docs/08 §六`）

### 6.3 三条禁令

- ❌ 不得用"感觉更流畅"充当 `3 原生` 的依据
- ❌ 不得把 `N 观测不可得` 写成 `1 不支持`（形态差异 ≠ 能力缺失）
- ❌ 不得把本表折算成任何分数并入 `results.md` 总分

## 7. 批次与成本（先跑 3 条，别一次上 10 条）

| 阶段 | 范围 | 场次 | 目的 |
|---|---|---|---|
