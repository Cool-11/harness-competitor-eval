## 模型、Skills 与 Harness 归因边界

六场固定了同题 prompt、inputs、checker、任务修订、全新会话、Skills/插件关闭、Memory 关闭和全文件权限，但没有固定同一底层模型：WorkBuddy 使用 DeepSeek-V4.1-Flash，豆包为 automatic-high，元宝为 default-expert。因此：

1. 本页只能表述为“产品 + 当前模型/默认配置”的整体观察；不能把 WorkBuddy 的速度或元宝的漏报单独归因于 Harness。
2. Skills 与 Memory 已在 prepare 配置快照中登记为关闭，降低了外部上下文污染，但桌面产品无法像 CLI 一样核验每个内部上下文注入。
3. Harness 因果结论继续只由 A 轨同模型 CLI 换件实验承担：固定模型、provider、sampling、环境、权限、网络和题包，只替换 Harness。
4. 桌面三款属于 B 轨产品结果比较，主要回答“当前产品配置能否完成任务、证据能否审计”，不发布底层模型能力排行。
