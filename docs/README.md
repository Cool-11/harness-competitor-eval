## 历史材料的使用边界

`05`、`15`、`19`、`23`、`25`、`26` 是旧场或试点的操作记录，用于解释当时的现场，不作为新运行指令。`13`、`14` 是未整体采纳的讨论稿；`16`、`21` 是专题研究材料。`reports/`、`周报/` 和 `sort/` 保留当时的分析与截止时间，不改写成当前状态。2026-11-09 清理掉的 `24`、`27`、`28`、`29` 是已被 v3 替代的执行卡，原文仍可从 Git 历史查看。

旧运行缺少运行前 `prepare.json` 时，不补造 `run_id`，也不追认正式准入。新场必须先 `prepare`，再投喂，最后 `collect` 和人工 `adjudicate`；`pending` 表示终裁尚未完成，不能用 checker 分数代替。
