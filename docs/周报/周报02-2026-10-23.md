## 二、本周难点突破

- **坎一：先跑测、后建目录，导致 3/5 条只能 retrofit** → 想通"现场优先于补录"：retrofit 只算产物分有效，不能声称行为/时间有效；此后先 `prepare` 再 `feed`，证据等级按"prepare 早于产物 + 外部日志 + 截图同源"三项判定 → S06 的 codex/dsh 两条升为完整现场，证据等级统一标 C，报告不据此写稳定性。
- **坎二：yuanbao 没有工作区导出，产物只存在于会话文件卡片** → 想通"形态不支持不等于 0 分"：从会话卡片导出并确认来源，按产品相对路径归档；同时设停止条件（两次导出失败即冻结为"形态不支持"，单列不判 0） → 覆盖从 4/5 补到 5/5，U-01 结清。
- **坎三：S06 五款全是 7.0/7，看起来"太整齐"，可能是题太浅，也可能是 checker 放水** → 没有用"五款都满分"直接下结论，而是回去测判卷器：K1/K2 证明放水真实存在（3.5→0.5、7.0→6.0） → 结论改为"本题产物分不区分产品，行为分才有区分（2.68–4.0）"，并在报告里写明单题不能外推五款稳定性。
