## 2. 本周难点与判断

- **「至少一个 baseline→change→recover 实验包」验收未达成。**P2 三臂是有效阴性筛查但三臂均 fail；S06 外部交付核查 C0 基线直接 7/7，无失败接缝可触发改件/恢复臂。经裁定暂停付费发射，后续须先解决读取隔离（现已通过）并另选可触发、可独立切换的组件。
- **作者复判不能当作独立评委验证。**黄钧锶 20 格复判 exact 90%、κ 0.9545 只能说明「作者复判与原判吻合」；因已见旧分，不满足「换人使用时评委可靠性」的验收，仍需真正未见旧分的人另填空白表。
- **读取隔离验证的环境阻塞。**Docker Desktop 的 WSL 引擎因 localhost 代理 + NAT 模式无法启动；通过 `.wslconfig` 加 `networkingMode=mirrored`、`wsl --shutdown`、重启 Docker Desktop 恢复后完成验证。该改动是系统级可逆配置，非仓库内容。
