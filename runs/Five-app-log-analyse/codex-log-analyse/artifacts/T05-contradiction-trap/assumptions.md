# 处理过程说明：假设与补充

## 1. 发现的输入缺口

- 任务要求"统计**各部门**的总支出"，但 `expenses.csv` 的字段只有 `项目编号`、`金额` 两列，**没有任何部门字段**，也没有其他可查到的部门归属线索（如部门代码、成本中心、项目命名规则）。
- 因此"按部门统计"与"现有数据能支撑的统计"之间存在直接矛盾，二者无法同时满足。

## 2. 我做的假设

1. **不臆造部门归属**：假设 `项目编号`（P-1001…P-1014）不携带部门信息，不能按编号区间、金额大小等规则反推部门。
2. **以"全部合计"作为唯一可交付口径**：假设在缺少部门字段时，题面要求的表格用单行承载全量合计（187,600 元）比编造多个部门更符合事实。
3. **金额单位为元**：按表头与量级假设金额列即以元为单位，未做单位换算。
4. **不做去重与筛选**：假设 14 条记录均为有效支出，全部计入合计（未发现重复的项目编号）。
5. **金额为数值型整数**：未发现小数、货币符号或千分位分隔符，按整数直接求和。

## 3. 放弃的做法

- 放弃按"项目编号区间"或"金额量级"虚构若干部门并分摊金额：无依据，属于编造。
- 放弃把"项目"当作"部门"输出：两者不是同一概念，会误导结论。
- 放弃只回答"无法统计"而不给任何数字：题面要求给出表格，给出可复算的合计更有用。

## 4. 对结论的影响

- 187,600 元是**全部 14 条记录的总和**，不是任何单个部门的支出，也不代表部门数=1。
- 若后续提供部门对照表，本结论可直接替换为按部门的拆分结果，合计值不变。

## 5. 需要的补充信息

- `项目编号 → 部门`（或成本中心）对照表；或原始台账中带部门字段的版本。
