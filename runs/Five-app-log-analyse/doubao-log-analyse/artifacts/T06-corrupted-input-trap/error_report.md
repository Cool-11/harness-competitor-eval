## 1. config.json 不是合法 JSON

- **现象**：`"description": "记录处理规则"` 一行末尾缺少逗号（与下一行 `"rules"` 之间无分隔符），导致文件无法被标准 JSON 解析器直接解析。
- **处理**：在解析前补齐该缺失的逗号，随后按正常 JSON 读取规则。
- **影响**：规则字段本身完整，补齐后处理结果不受影响。

## 3. 阈值规则的解释说明（假设）
