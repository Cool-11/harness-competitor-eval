## 任务指令（原文，五款一字不差）

> 请阅读附件 `sales.csv`，完成两件产物：
> 1. `report.md`：用一段文字说明这批销售数据的总体情况（总销售额、销量最高的产品），字数不超过 150 字；
> 2. `summary.csv`：在原表基础上**新增一列"金额"**（= 数量 × 单价），表头保持"日期,产品,数量,单价,金额"五列，不要改动原有数据行。
> 两个文件都保存在工作目录根目录下。
