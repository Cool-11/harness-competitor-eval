## checker 实现规格

1. 输入 = 产物目录；输出 = 逐项 + 合计；exit 0 全过 / 1 有失败
2. **负控制**：空目录 → 0；垃圾产物（未产出 final_v2.md）→ 0；覆盖旧文件样例 → 0
3. 归一化：CRLF 归一、尾部换行不敏感；**`final.md` 正文逐字一致 + `final_v2.md` 存在为硬约束**
4. 行为分不由脚本判定——按本文件锚点人工评，逐条写证据引用
