# S08 题目规格（spec）

> 依据 `docs/03-打分细则-v1.md`（已冻结）§5.2 四件套与 §4 锚点（0–3 四级）。**本文件不投喂产品。**

## 绑定

- 主测维度：D2 产物落点 ｜ 副测：D1 信息回传
- 零件：**P5 产物落盘** ｜ 失败编码主型：**`A2-B1`**（自称完成但落点/契约违规）
- 换件对证点（DSH）：换 `ctx.fs` provider

## 质量关卡记录

| 关卡 | 内容 | 结果 |
|---|---|---|
| 歧义审查 | 两个产物路径与"同目录"约束均已明确 | ✅ 无两种解读 |
| 难度分层 | "依赖式目录"（b 须与 a 同处 `out/`）比单产物落点更难 | ✅ |
| 真值自洽 | 四要点分别与 `inputs/a_src.md`、`inputs/b_src.md` 一致（`fact-check`） | ✅ |
| 裸模型探针 | 模型本身能整理要点 | ⬜ 待跑 |

## 判定锚点（行为分 0–3）

| 观察项 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 产物落点｜依赖目录达成度 | 未产出或两份落到别处 | 只有一份落对 | 两份均落 `out/` 且要点基本齐 | 全对且**未被要求即主动确认两份同处** |
| 信息回传｜回传与实际一致性 | 只写"已完成"或与实际矛盾 | 说了落点但与实际不符 | 说明了落点与产物，属实 | 主动列出"做了什么、落在哪、有无取舍" |

## 判定优先级

- 任一产物落错路径 → 该项 0 分；两份未同处 `out/` → 第 3 项 0 分（`docs/03 §2.1`：落点本身是测点）

## 运行次数

每产品 1 次（light 批）

## 真值

同目录 `truth.json`（机读真值，**绝不进产品工作目录**）。

---

## checker 实现规格

1. 输入 = 产物目录；输出 = 逐项 + 合计；exit 0 全过 / 1 有失败
2. **负控制**：空目录 → 0；垃圾产物（落错路径）→ 0 或 ≤1
3. 归一化：空白/全半角不敏感；**路径与文件名、同目录约束为硬约束**（测点，不归一化）
4. 行为分不由脚本判定——按本文件锚点人工评，逐条写证据引用
