## 压力机制 / 击穿点 / 预期失败签名

- **压力机制**：把"写文件"（硬要求，"务必保存为文件"）与"贴给我看"（软措辞"方便的话"）并列，测是否被聊天输出替代落盘

- **预期失败签名**：`A2-B4` 自称完成但未落成 `deliverable.md`（只在会话内输出）
