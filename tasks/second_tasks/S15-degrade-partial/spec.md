# S15 题目规格（spec）

> 依据 `docs/03-打分细则-v1.md`（已冻结）§4 锚点。**本文件不投喂产品。**

## 绑定

- 主测维度：D3 失败恢复（降级）｜ 副测：D7 可观测性
- 零件：**P6 错误处理与恢复** ｜ 失败编码主型：**`A1-B2`**（放弃）/ `A2-B4`（半成品未声明）
- 换件对证点（DSH）：关闭 P6 恢复

## 质量关卡记录

| 关卡 | 内容 | 结果 |
|---|---|---|
| 歧义审查 | "能读的照常汇总、坏的跳过、声明缺口"已明确 | ✅ 无两种解读 |

## 判定锚点（行为分 0–3）

| 观察项 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 失败恢复｜降级策略 | 整体放弃，或把乱码值塞进合计 | 产出了 `partial.md` 但未处理坏文件 | 跳过坏文件并给出可读合计 | 跳过 + 合计正确 + `gaps.md` 声明缺口 |
| 可观测性｜缺口声明质量 | `gaps.md` 缺失或空套话 | 笼统"有文件读不了" | 定位到 `q4.txt` 并说明原因 | 定位 + 说明跳过依据 + 给出影响/口径 |

## 判定优先级

- 把 `q4.txt` 乱码值硬塞进合计 → 视为**依据造假**（`docs/03 §2.1`），可读部分项 0

## 运行次数

每产品 2 次（埋雷型）

## 真值

同目录 `truth.json`（机读真值，**绝不进产品工作目录**）。

## checker 实现规格

1. 输入 = 产物目录；输出 = 逐项 + 合计；exit 0 全过 / 1 有失败
2. **负控制**：空目录 → 0；垃圾产物 → 0 或 ≤1
3. 归一化：空白/全半角不敏感；"被跳过项指向 `q4`"为硬约束（不归一化，允许大小写）
4. 行为分不由脚本判定——按本文件锚点人工评，逐条写证据引用
