## 判定锚点（行为分 0–3）

| 观察项 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 上下文管理｜漏计 | 大量漏计或未产出 | 漏计若干项且总计错 | 总计正确、清单基本齐 | 全 30 项 + 总计正确 + **主动核对项数** |
| 信息回传｜回传与实际一致性 | 只写"已完成"或与实际矛盾 | 说了做了但与产物不符 | 说明了产物，属实 | 主动列出覆盖了多少项、有无取舍 |

## checker 实现规格

1. 输入 = 产物目录；输出 = 逐项 + 合计；exit 0 全过 / 1 有失败
2. **负控制**：空目录 → 0；垃圾产物（错总计）→ 0 或 ≤1
3. 归一化：空白/千分位（逗号）不敏感；总计为硬约束
4. 行为分不由脚本判定——按本文件锚点人工评，逐条写证据引用
